ZT Git 隐私政策

生效及最后更新日期：2026 年 11 月 13 日

本政策适用于由 ZT 提供的 macOS 应用 ZT Git 及其产品和技术支持网站。本政策说明应用和网站如何处理信息，以及你可以如何管理相关数据。

一、我们处理的信息

ZT Git 是 Git 客户端，用于管理你选择的本地仓库。应用会读取和处理仓库中的文件、路径、Git 配置、提交历史、分支、标签及差异，以显示项目状态并执行你选择的操作。应用在本机保存项目列表、分组、最近打开的项目、账号配置及界面偏好，以便再次使用。

应用无需注册开发者运营的账号。除你主动连接指定的 Git 服务器，或主动向我们发送支持邮件的情况外，我们不通过应用收集你的数据。应用未集成广告、用户行为分析或第三方自动崩溃上报 SDK。

二、Git 服务器与远程通信

当你选择获取、拉取或推送等远程操作时，应用会与项目配置的 Git 服务器通信。根据操作和服务器配置，该服务器及其网络服务商可能收到 IP 地址、仓库请求、认证信息，以及你推送的代码、提交说明、作者信息和其他 Git 数据。

这些服务器可能由你、你的组织或第三方服务商运营。服务器对数据的使用和保留由其管理，并受相应服务的隐私政策和约定约束。我们不会仅因为你使用本客户端，就自动获得你发送给其他服务器的数据。请只连接你信任且有权访问的服务器。

三、账号与凭据

当你在应用中添加 Git 服务器账号时，账号名称、服务器地址、用户名及 SSH 私钥路径会保存在本机。你选择保存的 HTTPS 访问令牌或密码，以及可选的 SSH 私钥口令，保存在 macOS 系统钥匙串中。应用使用你选择的 SSH 私钥，但不会复制该私钥文件。

你可在“设置 → Git 服务器与账号”中编辑或移除应用内保存的账号。移除账号会删除应用为该账号保存的钥匙串凭据；其他系统 Git 配置、服务器账号及其数据不会因此自动删除。

四、本地数据、备份与删除

项目、Git 元数据、提交和导出文件保存在你的设备或你选择的位置。切换分支等操作可能在本机 Git 元数据目录中保存受影响的忽略文件副本；某些历史操作会保存 Git 引用，以便恢复。请根据需要自行管理这些仓库数据、备份、导出文件和废纸篓中的文件。

从应用列表移除项目只会移除列表记录，不会删除项目文件。卸载应用也不应视为已删除所有项目、导出文件、Git 备份或钥匙串凭据。你可以在应用中移除已保存的账号，并使用 Finder、系统设置及 Git 工具管理其余本机数据。删除本机数据不会删除 Git 服务器上的内容；如需处理服务器数据，请联系该服务器的管理员。

五、技术支持邮件

当你主动向 3193152800@qq.com 发送邮件时，我们会收到你的邮件地址、内容以及你选择提供的附件，用于处理问题和与你沟通；邮件服务提供商会处理收发和存储所需的信息。我们会在问题处理和必要的后续沟通结束后清理支持邮件和附件，法律要求保留的除外。

你可通过该邮箱请求访问、更正或删除我们收到的支持信息。我们会在核实请求并考虑适用义务后处理。请勿在邮件中发送密码、访问令牌、SSH 私钥或未获授权的项目代码；截图中的路径、账号和仓库地址也可以先脱敏。

六、网站及其他服务

本产品网站由 GitHub Pages 托管。访问网站时，GitHub 及相关网络服务商可能为提供和保护服务而处理 IP 地址等请求信息，详情见 GitHub 隐私声明。网站未嵌入我们设置的广告或用户行为分析脚本。

通过 App Store 下载应用或使用 Apple 的服务时，Apple 可能依其自身政策处理相关信息。第三方 Git 服务器、网站托管服务和邮件服务的处理方式，以其各自政策为准。

七、你的选择与联系方式

你可以自行选择本地项目和远程服务器、决定何时发起远程操作，编辑或移除应用中保存的账号，并联系 Git 服务器管理员管理服务端数据。如对本政策或支持邮件数据有疑问，或希望提出查询、更正或删除请求，请联系：3193152800@qq.com。

如应用功能或数据处理方式发生变化，我们会更新隐私政策及更新日期。
