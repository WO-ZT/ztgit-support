使用帮助

常见问题

运行要求：macOS 26.0 或更高版本，配备 Apple Silicon 芯片的 Mac。

需要单独安装 Git 吗？

ZT Git 内置适用于 Apple Silicon 的 Git，日常使用无需额外安装 Git 或 Xcode 命令行工具。Git LFS、GPG 等外部工具不包含在内；使用相应功能时需自行配置。

如何添加已有项目？

点击左上角“+”，选择“添加项目”，再选择包含 Git 仓库的本地项目文件夹或其中的子目录。也可以选择普通仓库的 .git 文件夹；项目支持按分组整理。

如何查看差异并提交？

打开项目后，在“更改”中选择文件查看差异，使用文件旁的“+”暂存需要提交的文件。输入提交说明后，点击提交按钮。存在未解决的冲突时需要先处理冲突。

远程连接或认证失败怎么办？

检查仓库地址、网络和账号权限。在“设置 → Git 服务器与账号”检查 HTTPS 凭据或 SSH 密钥配置，也可以使用系统 Git 配置。保存账号本身不会验证服务器权限。

首次连接新的 SSH 服务器时，请先与服务器管理员核对显示的主机指纹，再决定是否信任。

如何查看历史或导出历史版本？

切换到“历史”，可以使用列表或树状图查看记录，搜索已加载的提交。在指定提交上打开右键菜单，选择“导出此版本项目…”，将快照导出为 ZIP。导出不包含 .git、未提交更改和未跟踪文件，也不会额外下载子模块或 Git LFS 对象。

如何暂时保存并恢复更改？

在“更改”菜单选择“搁置…”，填写说明并确认。之后在左侧“搁置”中查看记录，通过右键菜单选择恢复并保留，或恢复并移除。恢复前请先处理当前工作区的更改。

合并或拉取时出现冲突怎么办？

根据工作区提示打开冲突处理界面。对于支持的文本冲突，可以选择一方的完整版本或手动编辑，保存并暂存后继续操作。部分特殊文件需要使用外部工具处理。

如何切换语言和外观？

打开“设置 → 通用”，选择简体中文、English 或跟随系统；外观可选择浅色、深色或跟随系统。设置会保存并立即生效。

反馈时，请附上这些信息

  • ZT Git 版本、macOS 版本和 Mac 芯片型号。
  • 执行了什么操作，预期结果与实际结果分别是什么。
  • 经过脱敏的错误信息、截图，以及可以重复问题的步骤。

请不要发送仓库密码、SSH 私钥、访问令牌或未获授权的项目代码。截图中的仓库地址、用户名和文件路径可先做遮盖。
